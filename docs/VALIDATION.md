# Границы подтверждённого результата

## Проверенный сценарий

Один пользовательский случай: Windows, оригинальная Shadow Fight 2 версии 2.46.0, iOS 27.2, перенос через iMazing. Пользователь подтвердил загрузку изменённого сохранения и работу валюты. Поведение не обобщается на все устройства, версии и функции игры.

До изменения была получена точная исходная пара XML/hash из собственного архива. Значение для соли обнаружено в экспортированных Preferences и проверено по исходной паре. Та же функция затем использована для нового основного XML и его резервной копии.

Нормализованные исходный и изменённый XML были отдельно сравнены с `.NET XmlDocument.OuterXml` с отключённым сохранением форматирующих пробелов. Для обоих конкретных файлов строки совпали. Остальные данные архива проверялись побайтово. Реальные сохранения и персональное значение соли не включены в публикацию.

## Проверки редактора

В `tests/` используются только искусственные XML и UUID. Тесты проверяют формулу, обнаружение значения по исходному хешу, изменение только указанных валют, неизменность исходника, сохранение посторонних записей и отказ от неверного хеша, неправильного идентификатора, перезаписи и неоднозначного ZIP.

Кроме синтетических тестов редактор проверяется локально на частном исходном архиве. Это не требует и не разрешает публикацию самого архива. GitHub Actions запускает синтетические тесты на Windows и Linux с Python 3.10 и 3.13.

## Дополнительные функции в v1.1.0: сферы и энергия

Редактор теперь технически поддерживает `ForgeMaterial1`, `ForgeMaterial2`, `ForgeMaterial3` в `Warrior/Currencies` и предмет `Unlimited_Energy` в `Warrior/Items`. Эти имена подтверждаются опубликованными примерами структуры сохранений SF2. На искусственных тестовых архивах проверяются структура XML, пересчёт хешей, неизменность других файлов и отсутствие дубликатов.

**Пользовательское подтверждение:** владелец проекта сообщил об успешном применении сфер зачарования и бесконечной энергии на своём iPhone. Это сообщение о результате на одном устройстве, а не независимое тестирование разных версий. Отдельная проверка всех вариантов через графический интерфейс на других устройствах пока отсутствует. Корректный HASH сам по себе не доказывает успешность каждой функции.

## Что не подтверждено

- Безопасный максимум монет или кристаллов.
- Успех на другом iPhone или после переустановки/смены идентификаторов.
- Универсальность способа получения UUID для всех iOS-экспортов.
- Бесконечная энергия и сферы на **других** устройствах и версиях, долгосрочное поведение после облачной синхронизации; снаряжение Титана, изменение сюжета, уровня и перков.
- Покупки, ресурсы и рейтинги, которые проверяются сервером.
- Самостоятельный перенос на iPhone без iMazing.

## Как добавить совместимость

Для новой версии нужны: нетронутый экспорт, воспроизведённый исходный хеш, контролируемое изменение одного параметра, проверка нового архива, успешный импорт и проверка прогресса на устройстве. В публичном отчёте достаточно обезличенных результатов и версий; персональные файлы не нужны.
