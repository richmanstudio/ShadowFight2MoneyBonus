# Расширенная инструкция: Shadow Fight 2 на iPhone

> **Не разбираешься в коде?** Начни с [простой инструкции для игроков](START_HERE.md) — там всё делается через готовую Windows-программу без Python. Этот документ нужен тем, кто хочет работать с командами и файлами вручную.

[← README](../README.md) · [Расчёт хеша](HASH.md) · [Ошибки](TROUBLESHOOTING.md)

## 1. Что именно мы меняем

Для монет и кристаллов в собственном свежем сохранении меняются два атрибута активного персонажа (отдельно редактор поддерживает экспериментальные сферы и энергию — см. раздел 6A):

```xml
<Warrior ID="1" Money="10000000" Bonus="1000" ... >
```

Это иллюстрация: многоточие нельзя вставлять в настоящий XML. `Money` — значение обычной сюжетной валюты, `Bonus` — кристаллов. Реальное отображение поздней валюты может зависеть от масштаба.

Редактор не заменяет сохранение чужим. Он оставляет уровень, опыт, инвентарь, бои и остальные записи вашего основного XML. Основной и резервный XML в новом архиве становятся одинаковыми. Прежний резервный XML остаётся в исходном архиве.

## 2. Подготовка

- Установите Python 3.10+ с [python.org](https://www.python.org/downloads/). На Windows проверьте `python --version`; если установлен только launcher, используйте `py` вместо `python` во всех командах.
- Установите iMazing с [сайта разработчика](https://imazing.com/). Этот проект не включает iMazing и не обещает бесплатность нужных функций.
- Скачайте репозиторий через **Code → Download ZIP**, распакуйте в отдельную папку. Откройте терминал в папке, где лежит `sf2save.py`.
- Подключите свой разблокированный iPhone к компьютеру и подтвердите доверие, если устройство попросит.
- Сделайте резервную копию iPhone. Сохраните пароль зашифрованной копии, если используете шифрование: скрипт не знает и не восстанавливает этот пароль.

## 3. Свежий экспорт — обязательный шаг

Завершите текущий бой, убедитесь, что нужный прогресс виден в игре, и закройте приложение. В iMazing выберите устройство → **Manage Apps / Управление приложениями** → **Device / Устройство** → Shadow Fight 2 → **Back Up / Резервная копия данных приложения**.

Выберите получение **текущих данных**, а не устаревшего снимка. Названия пунктов зависят от версии iMazing. Точный процесс описан в [официальном руководстве](https://imazing.com/guides/how-to-export-backup-and-transfer-ios-apps-data-and-settings).

Сохраните результат, например:

```text
D:\SF2\original.imazingapp
```

Сделайте вторую копию этого файла в отдельном месте. Не удаляйте SF2 с телефона. Не играйте между экспортом и импортом: инструмент не умеет объединять два расходящихся прогресса.

> Если уже есть `.imazingapp`, это ещё не значит, что он актуален. Сравните его уровень и валюту с игрой. При сомнении экспортируйте заново.

## 4. Осмотр архива

```powershell
python sf2save.py inspect "D:\SF2\original.imazingapp"
```

Команда выводит `Money`, `Bonus`, `Level`, `Experience`, `CurrentZone`, `DenominationDigits` и SHA-256 основного XML. Она не выводит идентификаторы аккаунта или устройства. `inspect` ничего не меняет и **не подтверждает** корректность хеша.

Поддерживается архив с путём `Container/Documents/userdata/` и один дополнительный внешний каталог, например `Shadow Fight 2/Container/...`. Скрипт сохраняет исходную структуру; распаковывать и упаковывать ZIP вручную не нужно.

## 5. Обязательная проверка исходного хеша

```powershell
python sf2save.py verify "D:\SF2\original.imazingapp"
```

Ожидается:

```json
{
  "original_hash_verified": true,
  "backup_hash_verified": true
}
```

Реальный вывод содержит и другие поля. Если резервного XML нет, `backup_hash_verified` отсутствует. Если он есть, но не прошёл проверку, вначале получите свежий экспорт и выясните причину расхождения.

Значение для соли ищется в настройках из этого же архива. Каждый кандидат проверяется по паре **исходный XML + его исходный `.hash`**. При отсутствии точного единственного совпадения `patch` останавливается. Другой iPhone, чужой UUID или случайный идентификатор не являются заменой проверке.

Если вы уже вручную изменили исходник, возьмите нетронутую копию или сделайте новый экспорт с телефона. Не переименовывайте XML в `.hash`, не копируйте старый `.hash` к новому XML и не удаляйте контрольные файлы в надежде, что игра их восстановит.

## 6. Изменение валюты

Для первого теста:

```powershell
python sf2save.py patch "D:\SF2\original.imazingapp" --output "D:\SF2\modified.imazingapp" --money 10000000 --bonus 1000
```

Только кристаллы, с сохранением текущего `Money`:

```powershell
python sf2save.py patch "D:\SF2\original.imazingapp" --output "D:\SF2\bonus-only.imazingapp" --bonus 1000
```

Не вводите пробелы, запятые, дроби или отрицательные числа. Ограничение инструмента в 30 цифр — защита от случайного ввода, **не предел игры и не рекомендация ставить такие суммы**. Безопасные максимумы на iOS не установлены. Примерные тестовые суммы выше не гарантируют принятие любой версией игры.

Редактор:

1. Проверяет исходный ZIP и исходный хеш.
2. Находит активного персонажа по `CurrentUser.ID`.
3. Меняет только указанные числовые атрибуты, сохраняя остальной текст XML.
4. Проверяет структуру XML до и после изменения.
5. Создаёт согласованные `users.xml`, `users.xml.hash`, `users_backup.xml`, `users_backup.xml.hash`.
6. Сохраняет содержимое прочих записей архива, включая `.lock` и plist.
7. Проверяет новый ZIP и записывает его под новым именем.

Проверьте готовый файл отдельно:

```powershell
python sf2save.py verify "D:\SF2\modified.imazingapp"
```

## 6A. Дополнительно: три сферы зачарования и бесконечная энергия

**Экспериментальная функция:** эти изменения пока не подтверждены запуском на iOS, в отличие от проверенного изменения обычной валюты. Для проверки используйте отдельную резервную копию.

- `ForgeMaterial1` — зелёные сферы;
- `ForgeMaterial2` — красные сферы;
- `ForgeMaterial3` — фиолетовые сферы.

Сферы хранятся в `Warrior/Currencies`. Если третьего атрибута ещё нет, инструмент добавляет `ForgeMaterial3` в существующий тег, не затрагивая остальные поля. Если сам тег `Currencies` отсутствует, инструмент выдаст ошибку — сначала откройте зачарование в игре.

```powershell
python sf2save.py patch "D:\SF2\original.imazingapp" --output "D:\SF2\orbs.imazingapp" --orb-green 100000 --orb-red 50000 --orb-purple 10000
```

Для бесконечной энергии:

```powershell
python sf2save.py patch "D:\SF2\original.imazingapp" --output "D:\SF2\energy.imazingapp" --unlimited-energy
```

В список `Warrior/Items` добавляется один предмет `Unlimited_Energy`. Если он уже есть, количество переводится в `1` без создания второго предмета. Энергию, сферы, монеты и кристаллы можно изменить **одной** командой, указав все нужные флаги. После сборки запустите `verify` для нового файла. Сохраните исходное сохранение; корректный хеш не доказывает работу дополнительных опций внутри игры.

## 7. Импорт на тот же iPhone

Закройте игру. В iMazing выберите **Manage Apps → Device → Restore App Data**, затем `modified.imazingapp`. Перед финальным действием убедитесь, что выбран ваш iPhone и именно новый файл.

iMazing может потребовать резервное копирование, шифрование копии, действия с «Локатором» и перезапуск устройства. Следуйте официальным подсказкам для своей версии iOS. Если появляется мастер настройки, не выбирайте стирание устройства; порядок экранов различается между версиями. Ориентируйтесь на [актуальную инструкцию разработчика](https://imazing.com/guides/how-to-export-backup-and-transfer-ios-apps-data-and-settings), а не на скриншоты старой iOS.

Этот Python-скрипт сам не запускает восстановление и не управляет настройками телефона.

## 8. Проверка результата

> [!CAUTION]
> **ПЕРЕД КАЖДЫМ запуском изменённой SF2:** включите **авиарежим** и отдельно **выключите Wi-Fi** в настройках iPhone. В авиарежиме Wi-Fi может продолжать работать, поэтому одной кнопки авиарежима недостаточно. Мобильный интернет также должен быть недоступен. Держите телефон полностью офлайн **с момента до запуска игры до её полного закрытия**. Это снижает риск, что при синхронизации появится или загрузится облачное сохранение вместо локального. Гарантии от любых проверок нет; сохраните исходный `original.imazingapp`.

После завершения импорта **сначала полностью отключите интернет**, затем откройте SF2. Повторяйте отключение связи **перед каждым следующим входом в игру**. Проверьте:

- баланс монет и кристаллов;
- уровень и опыт;
- текущую главу и открытые бои;
- экипировку и важные предметы.

Если игра всё же запущена с интернетом или показывает выбор сохранений, не подтверждайте облачный вариант автоматически. При сообщении о выборе облачного и локального прогресса внимательно сравните варианты. Нельзя гарантировать сохранение локальной модификации при загрузке другого облачного снимка. Не подтверждайте неизвестный вариант вслепую.

Работа интерфейса ещё не подтверждает серверные покупки или ресурсы рейдов. Если появилась ошибка повреждения данных, используйте [разбор ошибок](TROUBLESHOOTING.md).

## 9. Откат

Закройте SF2 и восстановите **нетронутый `original.imazingapp`** через тот же пункт iMazing. Вы вернётесь к состоянию на момент исходного экспорта. Более поздние бои не входят в этот файл.

Если проблема относится ко всему восстановлению устройства, используйте отдельную резервную копию iPhone и официальные инструкции iMazing. Не удаляйте единственный исходный архив, пока не убедились в результате.

## 10. Чего не нужно делать

- Не подменяйте свой XML скачанным «максимальным» сохранением: так теряется собственный прогресс и смешиваются идентификаторы.
- Не меняйте `ServerUserID`, `InstallID`, платёжные записи и `PaidBonus` ради видимого баланса.
- Не используйте инструкции по APK, Android ID, root или по Special Edition как доказательство совместимости обычной iOS-версии.
- Не включайте в публичные issues свои архивы, plist и полные XML. Достаточно версии программы, точного текста ошибки и обезличенного вывода команды.
