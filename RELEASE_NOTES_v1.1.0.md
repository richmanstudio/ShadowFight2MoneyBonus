# ShadowFight2MoneyBonus v1.1.0 — Coins, gems, enchantment orbs & Unlimited Energy

**First stable release including the enchantment-orb and energy controls.**

## What's included

- Edit **coins** (Money) and **gems** (Bonus).
- Edit **green, red, and purple enchantment orbs** (ForgeMaterial1, ForgeMaterial2, ForgeMaterial3).
- Add an **Unlimited_Energy** item to the existing character inventory.
- Offline **Windows graphical save editor** in Russian and English.
- Continue using your own original Shadow Fight 2 save, without jailbreak or third-party modified IPA.
- Validate original save integrity, recalculate both XML/hash pairs and preserve unrelated archive files.

## Quick start

1. Back up your iPhone and use iMazing to export a fresh, untouched Shadow Fight 2 app save (`original.imazingapp`).
2. Download **SF2-Save-Editor-Windows.exe** from this release, and run it on Windows.
3. Choose the original archive; click **Verify archive and HASH**.
4. Set the values you want; save the modified data to a **new .imazingapp file**.
5. Restore that new file through iMazing.
6. Before **every game launch** with a modified save, enable Airplane Mode, explicitly turn Wi-Fi off, and stay offline throughout play to reduce cloud-save overwrite risk.

## Validation

The project owner reports successfully using **coins, gems, all three enchantment-orb types and unlimited energy** on their iPhone. The documented baseline is original Shadow Fight 2 2.46.0, iOS 27.2, Windows and iMazing. This is **one device/user report**, not a guarantee for other game versions or iPhones. The GUI, archive integrity and hash algorithms have automated tests; the individual GUI workflows have not been independently certified across other devices.

This release uses the same editor features previously available in the v1.1.0-beta.1 build, now with an updated player-facing guide. Keep an untouched original and a full iPhone backup.

Windows executable is **unsigned**. Do not disable your system security settings to run untrusted software.
